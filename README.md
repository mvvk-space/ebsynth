# EbSynth (fork)

Fast Example-based Image Synthesis and Style Transfer — a fork of the upstream [EbSynth](https://github.com/sszhangp/EbSynth) project.

**Repository:** [mvvk-space/ebsynth](https://github.com/mvvk-space/ebsynth)

## What is EbSynth?

EbSynth transforms footage by painting a single keyframe: give it one stylized example frame and it propagates that style across the entire video sequence. It's example-based synthesis — fast, and no per-frame painting required.

## What's here

- `src/`, `include/`, `lib/` — the C++ source
- `bin/` — prebuilt binaries
- `examples/` — sample footage
- `doc/` — documentation
- Build scripts for Linux (CPU / CUDA), macOS (CPU), and Windows (32/64-bit, CPU / CUDA)

See the upstream README for full usage instructions.
